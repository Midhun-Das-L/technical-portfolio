# Generative AI

> Retrieval, reasoning and generation systems built on large language models.

| Module | Focus |
|---|---|
| [`RAG`](./RAG) | Retrieval-Augmented Generation pipelines: chunking, embeddings, vector search, re-ranking and grounded answers. |

| [`LLM-Applications`](./LLM-Applications) | End-to-end LLM products: chat assistants, summarisation, extraction and evaluation harnesses. |
| [`AI-Agents`](./AI-Agents) | Tool-using autonomous agents: planning, memory, multi-agent orchestration and guardrails. |
